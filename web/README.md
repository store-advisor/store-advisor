## Getting Started

First, run the development server:

```bash
cd store-advisor/web
```

then

```bash
npm install
```

## then for testing

```bash
npm test
```

You Should Get

```bash
Test Suites: 7 passed, 7 total
Tests:       86 passed, 86 total
Snapshots:   0 total
```

> **note** : if u didn't get that then probably the problem is in the API , API server must be running first. the Problem isn't mine XD

## then run dev server

```bash
npm run dev
```

# or

```bash
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
